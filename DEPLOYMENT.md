# Deployment Guide for Hostorio Laravel

Complete guide for deploying the Hostorio Laravel application to production.

## Updating the cPanel site (ho.demo.softorio.com)

Run these in cPanel → Terminal after new code is pushed:

```bash
cd /disk2/demosoftorio/ho.demo.softorio.com
PHP=/opt/cpanel/ea-php84/root/usr/bin/php

git fetch origin claude/clone-wp-ho-branch-r2rew7
git reset --hard origin/claude/clone-wp-ho-branch-r2rew7

$PHP artisan migrate --force                          # products tables, removes the old Package page plans
$PHP artisan db:seed --class=ProductSeeder --force    # first time only: imports the plans; does nothing once plans exist
$PHP artisan storage:link                             # once: needed for plan icons uploaded in the admin ("already exists" is fine)
$PHP artisan optimize:clear
```

Then check `.env` has `APP_ENV=production` and `APP_DEBUG=false`, and hard-refresh the browser (Ctrl + F5).
Run `composer install --no-dev --optimize-autoloader` only when `composer.lock` changed.

Plans and comparison tables are edited in the admin, see [docs/PRODUCTS_GUIDE.md](docs/PRODUCTS_GUIDE.md).
Titles, descriptions, verification codes and analytics are under Admin → SEO, see [docs/SEO_GUIDE.md](docs/SEO_GUIDE.md).

**Checks for SEO:**
- `APP_URL` in `.env` must be the site's real address (`https://ho.demo.softorio.com` on the demo,
  `https://hostorio.com` on the live site). With `APP_ENV=production` and an https `APP_URL`, every link,
  canonical and stylesheet is generated as https (so Cloudflare "Flexible" SSL can't cause mixed content);
  the site must therefore be reachable over https.
- Page addresses end in `/` (as on WordPress). Laravel adds the slash itself, so the web server must **not**
  remove trailing slashes. `public/.htaccess` no longer does. If the domain's document root is the project
  folder rather than `public/`, check that folder's `.htaccess` for a "Redirect Trailing Slashes" rule and
  delete it, or pages will redirect in a loop.
- On the demo site, turn on **Admin → SEO → SEO Settings → Hide this site from search engines**.
  On hostorio.com it must be off.

## Prerequisites

- Domain name with DNS access
- SSH access to server
- PHP 8.2+ installed
- MySQL or SQLite
- Nginx or Apache

## Option 1: Laravel Forge (Easiest)

### Step 1: Connect GitHub

1. Visit [Laravel Forge](https://forge.laravel.com)
2. Login with GitHub account
3. Create a new server

### Step 2: Deploy Application

1. Click "Create Server" → "App Server"
2. Select provider (DigitalOcean, AWS, Linode, etc.)
3. Choose Ubuntu 24.04
4. Add SSH key
5. Wait for server setup (~5-10 minutes)

### Step 3: Add Application

1. Click "New Application"
2. Select repository: `arifbillahcse/laravel-ho`
3. Choose PHP version: 8.2
4. Database: MySQL or PostgreSQL
5. Web directory: `/public`

### Step 4: Configure Environment

In Forge, add these variables:

```
APP_NAME=Hostorio
APP_ENV=production
APP_DEBUG=false
APP_URL=https://hostorio.com
APP_KEY=<generated by Forge>

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=hostorio
DB_USERNAME=<db-user>
DB_PASSWORD=<strong-password>

MAIL_MAILER=log
MAIL_FROM_ADDRESS=noreply@hostorio.com
```

### Step 5: First Deployment

1. In Forge, click "Deploy Now"
2. Or push to `main` branch (auto-deploy if enabled)
3. Forge will:
   - Clone repository
   - Install composer dependencies
   - Run migrations
   - Cache config

### Step 6: Setup SSL

1. In Forge, click "SSL" → "Install LetsEncrypt"
2. Choose auto-renewal
3. Verify HTTPS works

## Option 2: Manual VPS Deployment

### Step 1: Server Setup

```bash
# SSH into VPS
ssh root@your-vps-ip

# Update system
sudo apt update && sudo apt upgrade -y

# Install dependencies
sudo apt install -y curl gnupg2 ca-certificates lsb-release ubuntu-keyring

# Add PHP repository
curl https://packages.sury.org/php/apt.gpg | sudo apt-key add -
echo "deb https://packages.sury.org/php/ $(lsb_release -sc) main" | \
  sudo tee /etc/apt/sources.list.d/php.list

# Install packages
sudo apt install -y \
  php8.2-cli \
  php8.2-fpm \
  php8.2-mysql \
  php8.2-sqlite3 \
  php8.2-gd \
  php8.2-curl \
  php8.2-json \
  php8.2-bcmath \
  php8.2-xml \
  mysql-server \
  nginx \
  git \
  composer \
  certbot \
  python3-certbot-nginx
```

### Step 2: Create Deploy User

```bash
# Create user
sudo useradd -m -s /bin/bash deploy
sudo passwd deploy

# Add SSH key
sudo -u deploy mkdir -p ~/.ssh
sudo -u deploy chmod 700 ~/.ssh

# Copy your SSH public key
echo "your-ssh-public-key" | sudo -u deploy tee ~/.ssh/authorized_keys
sudo -u deploy chmod 600 ~/.ssh/authorized_keys

# Add to sudoers
sudo usermod -aG sudo deploy
```

### Step 3: Clone Application

```bash
sudo -u deploy -H bash << 'EOFBASH'
cd ~
git clone https://github.com/arifbillahcse/laravel-ho.git hostorio
cd hostorio
composer install --no-dev --optimize-autoloader
EOFBASH
```

### Step 4: Configure Application

```bash
# Copy env file
sudo -u deploy cp /home/deploy/hostorio/.env.example \
  /home/deploy/hostorio/.env

# Edit environment
sudo -u deploy nano /home/deploy/hostorio/.env
```

Edit these variables:
```
APP_ENV=production
APP_DEBUG=false
APP_URL=https://hostorio.com
APP_KEY=base64:YOUR_KEY_HERE

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_DATABASE=hostorio
DB_USERNAME=hostorio
DB_PASSWORD=<strong-password>
```

Generate app key:
```bash
sudo -u deploy php /home/deploy/hostorio/artisan key:generate
```

### Step 5: Setup Database

```bash
# Login to MySQL
sudo mysql

# Create database and user
CREATE DATABASE hostorio;
CREATE USER 'hostorio'@'127.0.0.1' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON hostorio.* TO 'hostorio'@'127.0.0.1';
FLUSH PRIVILEGES;
EXIT;

# Run migrations
sudo -u deploy php /home/deploy/hostorio/artisan migrate --force
sudo -u deploy php /home/deploy/hostorio/artisan db:seed
```

### Step 6: Configure Nginx

Create `/etc/nginx/sites-available/hostorio`:

```nginx
server {
    listen 80;
    server_name hostorio.com www.hostorio.com;
    root /home/deploy/hostorio/public;
    index index.php;

    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }

    # Cache static files
    location ~* \.(jpg|jpeg|png|gif|ico|svg|woff|woff2|ttf|eot|css|js)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

Enable site:
```bash
sudo ln -s /etc/nginx/sites-available/hostorio \
  /etc/nginx/sites-enabled/

# Remove default site
sudo rm /etc/nginx/sites-enabled/default

# Test and reload
sudo nginx -t
sudo systemctl reload nginx
```

### Step 7: Setup SSL/HTTPS

```bash
sudo certbot --nginx -d hostorio.com -d www.hostorio.com
# Follow prompts
# Choose auto-renewal
```

### Step 8: Set Permissions

```bash
# Set ownership
sudo chown -R deploy:deploy /home/deploy/hostorio

# Set permissions
sudo chmod -R 755 /home/deploy/hostorio
sudo chmod -R 775 /home/deploy/hostorio/storage
sudo chmod -R 775 /home/deploy/hostorio/bootstrap/cache
```

### Step 9: PHP-FPM Configuration

Edit `/etc/php/8.2/fpm/php.ini`:

```ini
max_execution_time = 30
max_input_time = 60
memory_limit = 256M
upload_max_filesize = 20M
post_max_size = 20M
```

Restart PHP-FPM:
```bash
sudo systemctl restart php8.2-fpm
```

### Step 10: Setup Cron Job

For Laravel scheduled tasks (if added later):

```bash
sudo -u deploy crontab -e
```

Add:
```
* * * * * cd /home/deploy/hostorio && php artisan schedule:run >> /dev/null 2>&1
```

### Step 11: Setup Logs

```bash
# Create log directory
sudo mkdir -p /var/log/hostorio
sudo chown deploy:deploy /var/log/hostorio

# Edit .env to log to file
# LOG_CHANNEL=single
# LOG_PATH=/var/log/hostorio/laravel.log
```

Monitor logs:
```bash
tail -f /var/log/hostorio/laravel.log
```

## Post-Deployment

### 1. Verify Installation

```bash
curl https://hostorio.com
# Should return HTML homepage
```

Check endpoints:
- https://hostorio.com/admin (should redirect to login)
- https://hostorio.com/sitemap.xml (should show XML)
- https://hostorio.com/robots.txt (should show robots)

### 2. Change Admin Password

1. SSH to server
2. Run: `php artisan tinker`
3. Execute:
   ```php
   $user = App\Models\User::find(1);
   $user->password = Hash::make('new-password');
   $user->save();
   ```

### 3. Test Admin Panel

1. Visit https://hostorio.com/admin
2. Login with new credentials
3. Test settings update
4. Verify changes appear on site

### 4. Setup Backups

**Option A: Forge Backups**
- In Forge UI, enable backups
- Choose backup frequency
- Select backup destination (S3, etc.)

**Option B: Manual Backups**
```bash
# Database backup
mysqldump -u hostorio -p hostorio > /backups/hostorio-$(date +%Y%m%d).sql

# Files backup
tar -czf /backups/hostorio-files-$(date +%Y%m%d).tar.gz \
  /home/deploy/hostorio/

# Upload to S3
aws s3 sync /backups/ s3://your-bucket/backups/
```

### 5. Setup Monitoring

**Email Alerts (Forge):**
- In Forge, set alert email
- Configure metrics threshold

**Manual Monitoring:**
```bash
# Check disk space
df -h

# Check memory
free -h

# Check PHP-FPM processes
ps aux | grep php-fpm

# Check Nginx errors
tail -f /var/log/nginx/error.log
```

### 6. Setup CDN (Optional)

If using CloudFlare:
1. Add domain to CloudFlare
2. Update DNS nameservers
3. Enable caching in CloudFlare dashboard
4. Set cache rules for `/assets/` (30 days)

## Troubleshooting

### 502 Bad Gateway
- Check PHP-FPM: `sudo systemctl status php8.2-fpm`
- Check logs: `tail -f /var/log/nginx/error.log`
- Restart PHP: `sudo systemctl restart php8.2-fpm`

### Blank Page / 500 Error
- Check app logs: `tail -f storage/logs/laravel.log`
- Check if cache is corrupted: `php artisan cache:clear`
- Verify `.env` values are correct

### Permission Issues
```bash
sudo chown -R deploy:deploy /home/deploy/hostorio
sudo chmod -R 755 /home/deploy/hostorio
sudo chmod -R 775 storage bootstrap/cache
```

### Database Connection Failed
- Verify MySQL running: `sudo systemctl status mysql`
- Check credentials in `.env`
- Test connection: `mysql -u hostorio -p hostorio`

### SSL Certificate Issues
```bash
# Renew certificate manually
sudo certbot renew --force-renewal

# Check certificate
sudo certbot certificates
```

## Performance Optimization

### Enable OPcache

Edit `/etc/php/8.2/fpm/conf.d/10-opcache.ini`:

```ini
opcache.enable=1
opcache.memory_consumption=256
opcache.interned_strings_buffer=16
opcache.max_accelerated_files=10000
opcache.revalidate_freq=60
opcache.fast_shutdown=1
```

Restart PHP-FPM.

### Enable Gzip Compression

Add to Nginx config:
```nginx
gzip on;
gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss;
gzip_min_length 1000;
gzip_disable "msie6";
```

### Use Redis for Caching (Optional)

```bash
sudo apt install redis-server

# In .env
CACHE_DRIVER=redis
```
